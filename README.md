# Riara University - Object-Oriented Programming in Java

This repository contains the Java code and practical session work for the Object-Oriented Programming course at Riara University.

## Structure

- **Week 1** - Introduction to Java
- **Week 2** - Variables, Data Types, and Operators
- **Week 3** - Conditionals: if-else, switch, ternary, debugging
- **Week 4** - Loops: while, do-while, for, nested loops, debugging

Each week's folder contains the Java programs created during that practical session.
